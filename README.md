# IPTV Monitor Android

Aplicación Android para consultar información de cuentas IPTV en servidores compatibles, con modo individual y verificación por lotes.

## Estado

Inicio del proyecto. La aplicación distinguirá entre datos ausentes, estados desconocidos y errores de conexión. No se deben incluir credenciales reales en el repositorio.

## Desarrollo

La implementación inicial se trabajará en una rama separada antes de integrarse en `main`.
